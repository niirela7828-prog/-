# פתק עבודה

אפליקציית Node.js קטנה, בלי תלויות חיצוניות, בעברית ובתאילנדית.

- **`/`**: טופס פתק עבודה לעובדים. אפשר לעבור בין עברית לתאילנדית בכפתור שבראש העמוד.
- **`/admin`**: עמוד המנהל. הכניסה אליו בסיסמה, ובו רואים ומוחקים את כל הפתקים.

## משתני סביבה

| משתנה | חובה | מה הוא עושה |
|---|---|---|
| `ADMIN_PASSWORD` | כן | הסיסמה לעמוד המנהל. בלי המשתנה הזה עמוד המנהל כבוי. |
| `DATA_DIR` | מומלץ מאוד | התיקייה שבה נשמר הקובץ `notes.json`. בשרת צריך להפנות אותה לאחסון קבוע (Volume). |
| `PORT` | לא | פורט השרת. ברירת המחדל היא 3000, ו-Railway מגדיר אותו לבד. |

## הרצה מקומית

```bash
ADMIN_PASSWORD=סיסמה-זמנית node server.js
```

אחרי זה פותחים את http://localhost:3000. עמוד המנהל נמצא ב-http://localhost:3000/admin.

## שינוי שדות הטופס

כל השדות מוגדרים בקובץ `fields.js`: שם, סוג, האם השדה חובה, והתווית בעברית ובתאילנדית.
את השדות משנים רק שם, וכל השאר מתעדכן לבד.

## פריסה ב-Railway

1. יוצרים פרויקט מה-repo (Deploy from GitHub repo).
2. מוסיפים Volume עם נקודת העגינה `/data`.
3. מגדירים את המשתנים `DATA_DIR=/data` ו-`ADMIN_PASSWORD=...`.
4. מפעילים כתובת ציבורית ב-Settings ← Networking ← Generate Domain.

כל push לענף שמחובר ל-Railway מעלה גרסה חדשה לאוויר אוטומטית.
